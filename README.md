# VFS Emulator

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой.

**Вариант:** №11 (ИКБО-63-25)  
**Этап:** 1 — REPL (минимальный прототип)  
**Язык реализации:** Python 3.10+

## Общее описание

Приложение реализует интерактивный REPL-интерфейс (Read-Eval-Print Loop),
имитирующий работу в командной строке UNIX-подобной ОС. На текущем этапе
реализован минимальный прототип: большинство функций представляют собой
заглушки, но диалог с пользователем уже поддерживается.

## Функции

### Реализованные команды

| Команда | Описание |
|---------|----------|
| `ls [path]` | Вывести содержимое директории (заглушка). |
| `cd <path>` | Сменить текущую директорию (заглушка). |
| `exit` | Завершить работу эмулятора. |

### Дополнительные возможности

- **Раскрытие переменных окружения** — поддержка синтаксиса `$VAR` и `${VAR}`.
  Например, ввод `echo $HOME` автоматически подставит значение переменной
  окружения `HOME`.
- **Обработка ошибок** — при вводе неизвестной команды выводится сообщение
  об ошибке, работа REPL не прерывается.
- **Обработка EOF** — корректное завершение при нажатии `Ctrl+D`.

## Настройки

На текущем этапе настройки задаются константами в коде:

- `DEFAULT_VFS_NAME` — имя VFS, отображаемое в приглашении (по умолчанию: `default_vfs`).
- `PROMPT_TEMPLATE` — шаблон приглашения к вводу.

В следующих этапах настройки будут вынесены в аргументы командной строки
и конфигурационные файлы.

## Сборка и запуск

### Требования

- Python 3.10 или выше
- (Опционально) `flake8`, `mypy`, `radon` — для проверки качества кода

### Запуск эмулятора

```bash
./run.sh

## Конфигурация

### Аргументы командной строки

| Аргумент | Обязательный | Описание |
|----------|--------------|----------|
| `--vfs-path` | Да | Путь к физическому расположению VFS. |
| `--script-path` | Нет | Путь к стартовому скрипту. |

### Примеры запуска

```bash
# Только интерактивный режим
./run.sh --vfs-path /tmp/my_vfs

# Со стартовым скриптом
./run.sh --vfs-path /tmp/my_vfs --script-path scripts/success.sh

# Справка
./run.sh --help
